# SaleBook — Commercial (Multi-Tenant SaaS)

The commercial, multi-tenant version of SaleBook: a sales-logging web app
that any small shop can sign up for, brand as their own, and pay to use.

This is the **product** version. The original single-shop build (made for
one shop, T-Max Store) lives in a separate private repo and is not part of
this codebase.

**Status: design-first.** See `PRD.md` for the full product requirements.
Nothing is built yet — the plan gets read and refined, then designed, then
built (in Claude Code / VS Code).
